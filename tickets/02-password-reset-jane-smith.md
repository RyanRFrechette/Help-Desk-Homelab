# Ticket 02 - Password Reset - Jane Smith

## Issue
Jane Smith reported that she could not sign in with her domain account.

## Environment
- Domain: `ryanlab.local`
- Domain controller: `RYANLAB-DC01`
- User account: `RYANLAB\j.smith`
- Tool used: Active Directory Users and Computers

## Troubleshooting Steps
1. Opened Active Directory Users and Computers on the domain controller.
2. Located Jane Smith under the RyanLab Users OU.
3. Used the Reset Password workflow for the account.
4. Confirmed Active Directory reported the password was changed successfully.

## Resolution
The password was reset successfully for Jane Smith. Screenshot 37 documents the successful password reset confirmation.
