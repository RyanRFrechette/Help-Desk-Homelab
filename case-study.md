# Help Desk Homelab Case Study

## Overview

This project documents the process of building a beginner-friendly Windows help desk homelab for remote IT support practice.

The goal is to show practical support readiness: setting up a lab, organizing evidence, using Windows tools, documenting steps, and preparing realistic ticket examples.

## Problem

Entry-level help desk applicants often say they can troubleshoot Windows issues, reset passwords, support users, and work with basic IT systems. This lab is designed to provide visible proof instead of only listing those skills on a resume.

## Solution

I created a structured virtual lab project using VirtualBox, Windows Server, Windows 11, PowerShell, screenshots, and GitHub documentation.

The lab is being built in phases:

1. Create project folder and documentation structure
2. Install VirtualBox
3. Download Windows Server and Windows 11 ISO files
4. Create a Windows Server VM
5. Create a Windows client VM
6. Configure beginner Active Directory tasks
7. Document help desk ticket scenarios

## Evidence Collected So Far

- Project folder structure created
- VirtualBox installed and verified
- Windows Server ISO downloaded and verified
- Windows 11 ISO downloaded and verified
- Windows Server VM setup started

## Skills Demonstrated

- Basic virtualization setup
- PowerShell command usage
- Software installation verification
- ISO download and validation
- Organized project documentation
- Screenshot evidence collection
- GitHub-based technical writing

## Planned Ticket Scenarios

The final project will include realistic support tickets such as:

- Password reset request
- Disabled account re-enable request
- New employee account setup
- Shared folder access issue
- Domain/client connectivity issue
- Basic Windows performance troubleshooting

## What This Shows a Hiring Manager

This project shows that I can work through an IT support process methodically, document what I did, and communicate technical steps clearly. It is intentionally practical and beginner-focused for help desk and remote IT support roles.

## Current Status

The project is in early buildout. The GitHub repository is live and the first setup screenshots are being organized into the documentation.
